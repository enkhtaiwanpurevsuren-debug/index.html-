Дэлхийн зах зээлийн судалгаа

Одоо ачаалсан хослолд тохирсон эрэлт-нийлүүлэлт, геополитик (дайн, хориг арга хэмжээ гэх мэт) мэдээг судлуулна. Энэ хэрэгсэл өөрөө интернэт хайлт хийж чадахгүй тул чат руу дуудлага илгээж, тэндээс бодит хайлт хийж хариулна. Хариултыг уншсаны дараа доор дүгнэлтээ тэмдэглэвэл техник шинжилгээтэй хамт харагдана.
1-р алхам: Судалгаа хийлгэх
—
2-р алхам: Дүгнэлтээ оруулах
Дээрх судалгааны хариултыг чатнаас уншаад, дүгнэлтээ энд тэмдэглэнэ үү — энэ нь Ижил төстэй загварын самбарт техник дохиотой хамт харагдаж, тохирч/зөрчиж байгааг илэрхийлнэ.
Судалгааны асуулт ачаалсан хослолын төрлөөс (үнэт метал / газрын тос / үр тариа / индекс / крипто / форекс) хамааран автоматаар өөрчлөгддөг — жишээ нь алт дээр төв банкны нөөцлөлт, газрын тос дээр OPEC+/хориг арга хэмжээ, үр тариа дээр Хар тэнгисийн коридор гэх мэт.

Эдийн засгийн календарь

Автомат календарь (TradingView)
Бодит, амьд шинэчлэгддэг мэдээний хуваарь — key шаардахгүй, TradingView-ийн нээлттэй widget. Зөвхөн энэ хуудсыг GitHub Pages (эсвэл өөр домэйн) дээр deploy хийсний дараа ажиллана — Claude чатны урьдчилан харах горимд гадаад script хориглогддог тул энд хоосон харагдана.
Хоосон харагдвал: ad-blocker унтраана уу, эсвэл deploy хийсэн жинхэнэ линкээр нээж үзнэ үү.
Гар аргаар бүртгэх (нэмэлт хэрэгсэл)
Дээрх автомат календарь ерөнхий мэдээ л харуулдаг — таны яг ачаалсан датан дээр тухайн мэдээ хэрхэн нөлөөлснийг тооцдоггүй. Тодорхой нэг мэдээг энд бүртгэвэл, тэр огноо ачаалсан түүхэн дата дотор байгаа эсэхээс хамааран ханшийн бодит хариу үйлдлийг доор автоматаар тооцно.

Гараар шинэчлэх

Сонгосон хослол/интервалд тохирох линк (browser-т нээгээд JSON-г бүгдийг хуулна уу):
Урт таамаг (50-100 bar) хийхэд илүү олон түүхэн дата хэрэгтэй. Линк доторх outputsize-ыг 5000 хүртэл нэмж болно (үнэгүй багцын кредит хязгаарыг анхаарна уу).
"Түүхийн урт"-ыг 1 жилээс дээш сонговол интервалаа 1 өдөр эсвэл түүнээс том сонгохыг зөвлөж байна — интраажийн интервалаар олон жил татахад дата хэт их болж, багц хязгаарт хүрч болзошгүй.
Энэ хэрэгсэл нь зөвхөн статистик, түүхэн загварын харьцуулалт хийдэг. Энэ нь санхүүгийн зөвлөгөө биш бөгөөд арилжааны шийдвэрийг өөрийн эрсдэлээр гаргана уу.
